## Purpose

Provide evidence-gated NVIDIA description ranking from immutable complete scores while preserving deterministic contractor selection and explicit failure behavior.

## ADDED Requirements

### Requirement: N1 Measured adoption
Semantic activation SHALL require real-provider access and source-supported benefit against a rubric recorded before model output. A failed, tied, inconclusive or over-timebox dense checkpoint SHALL preserve the accepted price policy and block dependent implementation. Activation SHALL additionally require both declared date pairs and another populated category without material unexplained regression.

#### Scenario: Dense checkpoint and rejection
- **WHEN** the same five eligible hosting profiles are compared with the price baseline within the initial 15-minute checkpoint
- **THEN** IDs, evidence grades, prices, latency, usage if available and all failures are recorded, and only concrete rubric improvement permits further integration

### Requirement: N2 Complete bounded generation
Generation SHALL use the fixed model and description-only passages for each represented category/format group, preserve full inputs, verify actual input limits and validate exactly one finite score per submitted index. Calls SHALL have a ten-second total deadline, cancellation and no automatic retries. Generation SHALL create a new immutable artifact only after complete validation and SHALL preserve previously accepted data on failure.

#### Scenario: Invalid or interrupted generation
- **WHEN** access, input fit, index coverage, score validity, deadline or cancellation fails
- **THEN** no accepted snapshot is replaced and a safe failure is recorded without credentials or fabricated scores

### Requirement: N3 Fixed validated ranking data
Semantic startup SHALL validate metadata, catalogue hash, digest and exact group/profile coverage, freeze one policy for the process lifetime and perform no NVIDIA request or ranking-state write during search. Its policy identity SHALL include snapshot content and algorithm version. Missing, corrupt or incompatible data SHALL produce explicit RANKING_UNAVAILABLE 503 with fresh requestId, never successful price fallback labelled semantic.

#### Scenario: Stability and unavailable data
- **WHEN** identical and unrelated requests run, the process restarts with the same snapshot, or NVIDIA is unreachable
- **THEN** identical requests preserve IDs and policy; malformed snapshot instead makes both public operations safely unavailable until valid restart

### Requirement: N4 Independent explanations and reproducible delivery
Semantic ranking SHALL retain the existing independent OpenAI quote/fallback behavior without changing selected IDs. Delivery SHALL disclose precomputed NVIDIA provenance, regeneration, rollback and cost limitations. Adoption SHALL include three complete browser timings under ten seconds, mobile/keyboard checks and clean committed installation/build/launch without a NVIDIA key for search.

#### Scenario: Real candidate acceptance
- **WHEN** real selected-card evidence, provider fallback, repeated/restarted search and clean README launch are checked
- **THEN** observed results are tied to exact revisions and distinguished from controlled fixtures and historical checks, with all unavailable checks explicitly unmet
