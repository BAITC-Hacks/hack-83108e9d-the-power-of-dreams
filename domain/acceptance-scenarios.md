# Сценарии приёмки

## Проверки работающего решения

Проверять вживую. Этот документ задаёт ожидаемые проверки; выполненной приёмки приложения пока нет.

| Сценарий | Наблюдаемый результат |
|---|---|
| Обычный подбор | До трёх карточек со всеми полями из [постановки](problem-and-scope.md); ориентир времени ответа — до 10 секунд |
| Качество объяснений | 1–2 предложения, конкретные факты профиля и запроса; после удаления имён объяснения различимы |
| Повтор запроса | Порядок карточек совпадает |
| Смена только даты | На подобранной паре дат выдача меняется; причина через занятость понятна пользователю |
| Занятый профиль | Отсутствует среди рекомендаций, включая случай площадки |
| Подходящих один или два | Все показаны, объяснено, почему меньше трёх |
| Нет категории в городе | Явный исход отсутствия категории |
| Есть кандидаты, никто не проходит | Другой явный исход с причинами отказа; не пустой экран и не ошибка |
| Добавленные командой профили, если есть | Имеют `synthetic: true`; происхождение различимо в демо |
| Объяснение устройства | Команда может описать фактические этапы отбора, ранжирования и формирования объяснений |

Минимальная демонстрация из постановки: плотная категория на осеннюю дату с реальным выбором между кандидатами, редкая категория и запрос без результата. Проверка обоих видов пустой выдачи нужна для требования о трёх различимых исходах.

## Проверенные заготовки запросов

Ниже результат чтения CSV, не запуска сервиса. Для подсчёта использованы совпадение города, вхождение категории и формата, `price_from_kzt ≤ бюджет`, отсутствие даты в `busy_dates`. Язык и длительность не заданы. Это явное допущение проверки данных; правила будущего сервиса согласуются в OpenSpec.

| Случай | Город / категория / формат / дата / бюджет | Ожидание по данным |
|---|---|---|
| Плотная категория | Алматы / Ведущий / корпоратив / 2026-10-10 / 1 500 000 ₸ | 5 подходящих, есть из кого выбрать тройку |
| Другая дата | То же, дата 2026-10-11 | 4 подходящих; состав отличается |
| Редкая категория, неполная тройка | Алматы / Флорист / свадьба / 2026-10-10 / 500 000 ₸ | 1 подходящий; второй флорист города занят |
| Кандидаты не проходят | Алматы / Ведущий / корпоратив / 2026-10-10 / 1 ₸ | Категория есть; ни один профиль не проходит по бюджету |
| Категории нет в городе | Зарубежье / Флорист / свадьба / 2026-10-10 / 500 000 ₸ | Нет флористов в этом городе |

Наборы подходящих ID для проверки, **не эталон ранжирования**:

- Ведущие, 10 октября: `HK-88430`, `HK-77838`, `HK-27222`, `HK-75012`, `HK-29829`.
- Ведущие, 11 октября: `HK-44733`, `HK-44923`, `HK-77838`, `HK-27222`.
- Флорист, 10 октября: `HK-39372`; `HK-90001` занят.

У двух наборов ведущих только два общих профиля, поэтому при выдаче трёх карточек состав обязательно изменится. Порядок внутри наборов не утверждён. Примеры перепроверяются при изменении датасета; допустимость крайних входов вроде бюджета 1 ₸ зависит от будущей валидации.
