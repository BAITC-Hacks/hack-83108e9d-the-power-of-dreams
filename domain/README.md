# Доменный контекст: подбор event-подрядчиков

Начинайте здесь. Эта папка содержит очищенную постановку задачи #79-lite и проверенные сведения об исходном наборе данных. Для обычной работы не читайте `raw` целиком.

## Что читать

| Задача | Документ |
|---|---|
| Понять продукт и границы | [Проблема и объём](problem-and-scope.md) |
| Разобраться в поведении подбора | [Модель и правила](model-and-rules.md) |
| Подключить или интерпретировать данные | [Контракт данных](data-contract.md) |
| Проверить результат | [Сценарии приёмки](acceptance-scenarios.md) |

Загружайте только документ, нужный для текущей задачи. Полные профили и календари читает приложение; при исследовании конкретного случая выбирайте записи по ID.

## Источники и границы достоверности

| Источник | Что сохранено | Роль дальше |
|---|---|---|
| `raw/proposal.md` | Требования, ограничения, DoD, оценка | Архив исходной постановки |
| `raw/dataset.csv` | Схема, значения, статистика, примеры для проверок | Машинный ресурс приложения |
| `raw/metadata.md` | Проверено совпадение всех 66 ID с CSV | Архивное представление каталога; описания местами обрезаны |

Сверка выполнена 2026-09-23. Рекламные тексты, перечни клиентов, биографии и повторяющиеся карточки не перенесены в документацию. Полные `description` остаются в CSV для смыслового подбора и объяснений; сокращённый каталог не заменяет их.

`domain` — рабочий справочник исходных условий. Активные требования конкретного изменения, принятые технические решения и состояние задач ведутся в [OpenSpec](../openspec/); архитектура — в [architecture](../architecture/README.md). Здесь не утверждены алгоритм, API или стек продукта. Новые решения следует связывать ссылками, не копировать в несколько документов.

Архив нужен только при изменении исходников, споре о формулировке или проверке происхождения факта. После изменения CSV пересчитайте статистику и примеры в этой папке. Не считайте синтетические данные реальными анкетами: даже несинтетические профили анонимизированы, а часть полей заполнена при подготовке.
