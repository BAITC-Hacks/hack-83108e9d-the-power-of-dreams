# Контракт исходных данных

## Файл и представление

В репозитории предоставлен `raw/dataset.csv`: UTF-8, заголовок и 66 записей, 13 колонок. Упомянутые в постановке JSONL и HTML не предоставлены. `metadata.md` — текстовое превью, не источник для загрузки.

CSV использует запятые между колонками и кавычки для текстов с запятыми. Внутри списковых полей разделитель `|`. Используйте CSV-парсер, не разделение строки по запятой. Ниже описано представление источника, не публичный HTTP-контракт.

| Поле | Значение и представление |
|---|---|
| `id` | Строковый идентификатор вида `HK-39372`; все 66 уникальны |
| `anon_name` | Вымышленное имя профиля |
| `categories` | Одна или несколько категорий через `|` |
| `city` | Город или значение `Зарубежье` |
| `city_imputed` | `TRUE` / `FALSE`: город проставлен при подготовке |
| `synthetic` | `TRUE` / `FALSE`: полностью синтетический профиль |
| `price_from_kzt` | Целое число, стартовая цена в тенге за мероприятие |
| `price_imputed` | `TRUE` / `FALSE`: цена проставлена при подготовке |
| `event_formats` | Поддерживаемые форматы через `|` |
| `languages` | Языки работы через `|` |
| `max_hours` | Максимум часов на площадке; пустая CSV-ячейка соответствует `null` — присутствие неприменимо, не ноль часов |
| `busy_dates` | Занятые даты `YYYY-MM-DD` через `|` |
| `description` | Полный свободный текст на русском; материал для смыслового подбора и объяснений, содержит также рекламу |

## Качество и ограничения

- 13 профилей синтетические; у 8 проставлен город, у 18 — цена. Флаги могут пересекаться.
- 9 пустых `max_hours`: флористы, декораторы, подарки и сувениры. По 3 профиля каждой категории.
- Цены заполнены у всех; наблюдаемый диапазон — 100 000–6 000 000 ₸. Города также заполнены у всех.
- Профили анонимизированы; по постановке дополнительная анонимизация не требуется. Рейтинги, биографии и рекламные заявления из описаний не являются независимо проверенными фактами.
- Календарное окно: **2026-09-23–2026-12-31 включительно**, 100 дней. Занятость задана по целым датам; время суток и частичные пересечения не представлены.
- По постановке занятость в сентябре–ноябре составляет 30–50%, в декабре — 70–80%. Это описание подготовки набора, не гарантия свободного кандидата для любого запроса. Пустая выдача в декабре ожидаема.
- Из стартовой цены нельзя вывести окончательную стоимость, почасовую ставку или цену на одного гостя. Вместимость, рейтинг и условия выезда не представлены отдельными структурированными полями.

Статистика проверена по CSV 2026-09-23; она описывает текущий снимок, а не ограничения будущих данных.
